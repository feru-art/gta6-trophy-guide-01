GTA VI Trophy Guide — an offline guide and tracker for all 55 Grand Theft Auto VI PlayStation 5 trophies: a checklist with progress saved in the browser, filters by kind, a spoiler setting, export and import, a roadmap to platinum, missable flags built from the official descriptions, and a guide for each trophy in our own words that cites its sources. Built by an AI agent for make.fun's “Build the best GTA 6 trophy guide” bounty, $250 in USDC.

## Run it

```sh
python3 -m http.server 8080 --directory app
# then open http://localhost:8080 in desktop Chrome (works with the network off)
```

Or build the entry output with Node 22:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
